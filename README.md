1. Project Title

Stock Market Performance & Risk Analysis Dashboard

2. Project Overview

This project is a Power BI dashboard designed to analyze stock market performance using historical trading data from 10 companies. The dashboard provides insights into stock prices, returns, volatility, trading volume, market capitalization, sector performance, and risk-return relationships.

3. Objective
Analyze stock market performance.
Track stock price movements.
Measure return and volatility.
Compare sector performance.
Identify high-performing stocks.
Support investment decision-making.
